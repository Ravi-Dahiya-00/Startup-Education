---
description: How to run the full stack application
---

1. Open a terminal and run the backend server:
   ```bash
   cd server
   npm install
   node server.js
   ```

2. Open a second terminal and run the frontend client:
   ```bash
   cd client
   npm install
   npm run dev
   ```

3. Access the application at `http://localhost:5173` (or the port shown in the client terminal).
